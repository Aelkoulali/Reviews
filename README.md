# 🗂️ Guest Hotel Reviews ✍🏻 ⭐️⭐️⭐️⭐️⭐️ 
Guest Hotel Reviews is a web project built with HTML, CSS, and JavaScript. It shows hotel guest reviews with star ratings and updates the content dynamically.

The app uses Math.random() and Math.floor() to randomly pick a review and generate a valid rating, and addEventListener() to trigger the update when the user interacts (like clicking a button).

## ✅ Key Features
- Displays guest reviews with a rating (stars) for each review.
- Generates review/rating data dynamically to keep the UI fresh.
- Uses Math.random() to select a random review and Math.floor() to convert random values into valid star/selection indexes.
- Uses addEventListener() to run the generation when the user clicks a button (e.g., “Show Review”) or performs another action.

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript:
    - random selection using Math.random()
    -  valid integer conversion using Math.floor()
    - user interaction using addEventListener()

## ▶️ How to Run
1. Open `index.html` in your browser.
